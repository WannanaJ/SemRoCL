================================================================================
INSTALLATION STEPS
================================================================================

1. Copy project to: D:\projects\SemRoCL\
2. Install environment: conda env create -f environment.yml
3. Activate environment: conda activate semrocl
4. Download datasets to data/ folder
5. Run Stage 1 training: python src/train_stage1_moco.py
6. Run Stage 2 training: python src/train_stage2_enhance.py
7. Evaluate results: python src/evaluate.py
